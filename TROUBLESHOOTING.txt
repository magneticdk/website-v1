===========================================
🚨 COMMON LOCALHOST ISSUES & FIXES
===========================================

PROBLEM 1: "This site can't be reached"
─────────────────────────────────────────
Cause: Server not running
Fix:
  1. Open PowerShell in the project folder
  2. Run: npm run dev
  3. Wait for "Local: http://localhost:5173"
  4. Try browser again

PROBLEM 2: Port already in use
─────────────────────────────────────────
Cause: Another app using port 5173
Fix:
  • Vite will auto-use next port (5174, 5175, etc.)
  • Check terminal for actual URL
  • Or kill the process:
    Get-Process -Id (Get-NetTCPConnection -LocalPort 5173).OwningProcess | Stop-Process

PROBLEM 3: Browser shows blank page
─────────────────────────────────────────
Cause: Build error or cache issue
Fix:
  1. Check terminal for error messages
  2. Hard refresh: Ctrl + Shift + R
  3. Clear browser cache
  4. Try different browser

PROBLEM 4: "npm: command not found"
─────────────────────────────────────────
Cause: Path not updated after Node.js install
Fix:
  1. Close and reopen PowerShell
  2. Or run: $env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
  3. Then: npm run dev

PROBLEM 5: Changes not showing
─────────────────────────────────────────
Cause: File not saved or HMR issue
Fix:
  1. Save file: Ctrl + S
  2. Wait 1-2 seconds
  3. Hard refresh: Ctrl + Shift + R
  4. If still not working, restart server

PROBLEM 6: Server stopped unexpectedly
─────────────────────────────────────────
Cause: Terminal closed or process killed
Fix:
  • Run again: npm run dev
  • Keep terminal window open
  • Server runs in foreground

===========================================
🌍 ACCESS FROM OTHER DEVICES
===========================================

Want to view on phone/tablet?

1. Find your computer's IP:
   ipconfig
   (Look for IPv4 Address, e.g., 192.168.1.XXX)

2. Start server with host flag:
   npm run dev -- --host

3. On other device, browse to:
   http://YOUR-IP:5173
   (e.g., http://192.168.1.100:5173)

Note: Both devices must be on same WiFi network

===========================================
⚠️ FIREWALL ISSUES
===========================================

If firewall blocks access:

Windows:
  1. Search "Windows Defender Firewall"
  2. Click "Allow an app through firewall"
  3. Find "Node.js" and check both boxes
  4. Click OK

Or temporarily:
  • Allow when Windows asks
  • Choose "Private networks"

===========================================
🔄 RESTART PROCEDURES
===========================================

Quick Restart:
  1. Ctrl + C (stop server)
  2. npm run dev (start again)

Full Restart:
  1. Ctrl + C (stop server)
  2. Close terminal
  3. Open new PowerShell
  4. cd to project folder
  5. npm run dev

Clean Restart (if having issues):
  1. Ctrl + C (stop server)
  2. Remove node_modules: rm -r node_modules
  3. Reinstall: npm install
  4. Start: npm run dev

===========================================
🐛 ERROR MESSAGES & FIXES
===========================================

"EADDRINUSE: address already in use"
  → Port 5173 is busy
  → Vite will auto-use next port
  → Or kill existing process

"Cannot find module"
  → Run: npm install
  → Then: npm run dev

"Permission denied"
  → Run PowerShell as Administrator
  → Or check file permissions

"Failed to load config"
  → Check vite.config.js syntax
  → Ensure all files are saved
