===========================================
CUSTOMIZATION GUIDE
===========================================

📝 UPDATE YOUR PROFILE:
   File: src/components/ProfileSection.jsx
   - Change "Your Name" to your actual name
   - Update the bio text
   - Replace the avatar URL with your own image

🔗 ADD/EDIT LINKS:
   File: src/App.jsx
   Find the "links" array and modify:
   - title: The text shown on the button
   - url: Where the link goes
   - icon: Any emoji you like (💼 🎨 📱 etc.)

🌐 UPDATE SOCIAL MEDIA:
   File: src/App.jsx
   Find the "socialLinks" array and change the URLs to your profiles

🎨 CHANGE COLORS:
   Files to edit:
   - src/index.css (main background gradient)
   - src/components/LinkCard.css (button colors)
   - src/components/SocialLinks.css (social icon colors)
   
   Current gradient: #667eea to #764ba2
   Try these alternatives:
   - Pink/Orange: #f093fb to #f5576c
   - Blue/Green: #4facfe to #00f2fe
   - Sunset: #fa709a to #fee140

===========================================
USEFUL COMMANDS
===========================================

Start Development Server:
   npm run dev

Build for Production:
   npm run build

Stop Development Server:
   Press Ctrl+C in the terminal
