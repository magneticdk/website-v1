EXAMPLE 5: ADD YOUR OWN IMAGE
===========================================

Option A: Use a URL (easiest)
In src/components/ProfileSection.jsx:
<img 
  src="https://yourwebsite.com/your-photo.jpg" 
  alt="Profile Avatar"
/>

Option B: Use local image
1. Create public folder: mkdir public
2. Add your image: public/avatar.jpg
3. Update ProfileSection.jsx:
<img 
  src="/avatar.jpg" 
  alt="Profile Avatar"
/>

Option C: Generate avatar (current method)
Change the seed in ProfileSection.jsx:
src="https://api.dicebear.com/7.x/avataaars/svg?seed=YourName"

Try different styles:
- avataaars (current)
- bottts (robots)
- identicon (geometric)
- initials
- pixel-art

EXAMPLE 7: CHANGE FONTS
===========================================

Add to src/index.css before :root:

@import url('https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap');

Then update in :root:
font-family: 'Poppins', Inter, system-ui, sans-serif;

Popular font combinations:
- Montserrat (headers) + Open Sans (body)
- Playfair Display (headers) + Lato (body)
- Raleway + Roboto
- Nunito (friendly & modern)

EXAMPLE 8: ADD ANIMATION EFFECTS
===========================================

Add to src/App.css for staggered link animations:

.link-card {
  animation: slideIn 0.5s ease-out backwards;
}

.link-card:nth-child(1) { animation-delay: 0.1s; }
.link-card:nth-child(2) { animation-delay: 0.2s; }
.link-card:nth-child(3) { animation-delay: 0.3s; }
.link-card:nth-child(4) { animation-delay: 0.4s; }

@keyframes slideIn {
  from {
    opacity: 0;
    transform: translateX(-20px);
  }
  to {
    opacity: 1;
    transform: translateX(0);
  }
}
