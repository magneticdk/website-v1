===========================================
🆘 TROUBLESHOOTING
===========================================

Server not starting?
  → Run: npm install
  → Then: npm run dev

Port 5173 already in use?
  → Vite will automatically use 5174, 5175, etc.

Changes not showing?
  → Save the file (Ctrl+S)
  → Browser should auto-refresh

Build errors?
  → Check console for error messages
  → Ensure all imports are correct
